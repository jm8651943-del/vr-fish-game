# Fish Arena — Neon Reef 2D

The `fish-arena-web` service deploys this standalone, landscape-first **2D Canvas** arcade from `feature/mobile-arcade-controls-20261113`. It uses procedural original reef/fish illustrations, targetable fish, cannons, power levels, boss waves, special weapons, demo credits, and tap/hold mobile controls.

The distinct VR/Quest production services continue following `main`; **do not merge this 2D entry page into main without a separate VR rollout plan.**

No real-money gambling, purchase, withdrawal, or cash redemption is implemented. Demo credits have no cash value. Admin sliders are local game configuration only.

Deployment URL: https://fish-arena-web-production.up.railway.app/.
